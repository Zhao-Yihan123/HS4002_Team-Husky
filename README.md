# HS4002_Team-Husky
How the perceived prevalence of sexual harassment in one’s neighborhood is associated with subjective security, and is this association stronger among women than among men? 

## Repository structure

- `data/raw/`: Original data files.
- `data/processed/`: Cleaned or transformed data files.
- `code/`: Analysis scripts and notebooks.
- `output/figures/`: Generated figures.
- `output/tables/`: Generated tables.
- `slides/`: Presentation materials.
